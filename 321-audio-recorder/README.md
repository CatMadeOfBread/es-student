## Таймаут сторожевого таймера

Для непрерывной записи я бы выбрал таймаут **8 мс**. В пятисекундном прогоне самая долгая итерация суперцикла заняла 1,457 мс. Таймаут даёт примерно 5,5-кратный запас к этому замеру. Буфер из 512 отсчётов заполняется примерно за 11,6 мс, поэтому при зависании таймер сработает раньше, чем истечёт время заполнения целого буфера. В испытании с командой `hang` используется таймаут 2000 мс, чтобы успеть наблюдать поведение индикатора и USB-порта.
